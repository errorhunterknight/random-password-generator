
A simple Python project that generates secure random passwords.

## Features
- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Secure random character selection

## Technologies Used
- Python 3
- Random module
- String module

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

python3 password-generator.py

4. Enter your desired password length.
